# 動作確認用のサンプル

`github-html-preview` の挙動を確認するためのサンプルドキュメントです。拡張機能の動作には不要なので、Chrome ウェブストア用の ZIP には含めません。

## 使い方

1. 拡張機能を Chrome に読み込みます（[インストール手順](../github-html-preview/README.md#インストール)）。
2. GitHub 上で [`demo/index.html`](index.html) を開きます。
3. 画面右下の **HTML Preview** を押します。
4. ページ内の 1〜7 の項目がすべて「OK」の表示になっていることを確認します。
5. 項目 7 のリンクから [`日本語のファイル名.html`](日本語のファイル名.html) に移動し、8〜10 を確認します。

## 注意

`index.html` をブラウザで直接開くと、項目 6 は赤い「JavaScript: 実行された（想定外）」になります。通常のブラウザではスクリプトが動くためで、これが正しい状態です。拡張機能のプレビュー越しに見たときだけ緑のままになります。

## 各ファイルが確認していること

| ファイル | 確認内容 |
| --- | --- |
| `index.html` | 相対パスの外部CSS、インライン `<style>`、インライン `style` 属性、ページ内リンク、スクリプトが実行されないこと |
| `styles/theme.css` | `@import` の展開、CSS の `url(...)` による背景画像 |
| `styles/base.css` | `@import` された側のスタイルが適用されること |
| `assets/diagram.svg` | `<img>` の相対パス画像 |
| `日本語のファイル名.html` | 日本語ファイル名、別HTMLへの相対リンク、読み込み失敗時の警告表示 |
